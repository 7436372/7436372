我目前从事制造业数字化项目，兼具 **产品经理、低代码开发工程师、Java 开发工程师** 三类角色经验，主要关注 **MES / MOM / WMS** 等工厂数字化系统的规划、设计、开发与交付。

## 我的产品视角

我认为一个好的制造业数字化系统，不只是“功能完整”，还要真正能在现场跑起来：

- 流程边界清晰，岗位职责明确。
- 界面和交互要适合一线人员使用，而不是只服务于报表展示。
- 数据要能从物料、工序、质量、设备一路追溯到库存和成本。
- 数据模型要能承受真实工厂里的异常、返工、补录、拆批、合批和部分报工。
- 交付方式要循序渐进，先解决关键痛点，再逐步扩展平台能力。
